# 校园失物招领（WEB 版）

福州大学《H202601 软件工程与软件工程实践》2026 秋第二次结对作业——基于第一次结对作业原型设计的程序实现。

- 结对成员：102401337 吴昊阳、102401335 郭航铭
- 呈现形式：WEB

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 浏览信息 | 首页信息流，支持「全部 / 寻物 / 招领」分类切换，按发布时间倒序 |
| 发布信息 | 寻物 / 招领两种类型，填写名称、分类、地点、时间、描述、联系方式，可上传照片（选填），带完整表单校验 |
| 搜索物品 | 关键词搜索（命中名称、地点、描述、分类），支持类型 / 分类 / 地点组合筛选，热门搜索词，结果关键词高亮 |
| 查看详情 | 展示物品完整信息、发布者与联系方式 |
| 联系发布者 | 详情页一键复制联系方式 |
| 更新状态 | 发布者可将信息标记为「已找到 / 已归还」，标记后联系方式自动隐藏；支持删除自己的信息 |
| 我的发布 | 集中管理本人发布的信息，含全部 / 进行中 / 已完成统计 |
| 附加特点 | 空状态提示（无数据 / 搜索无结果）、表单逐项报错、相对时间显示、一键复制、演示数据一键重置、localStorage 本地持久化 |

> 本次作业不要求复杂后台、实名认证、即时聊天与地图定位，故当前用户为固定演示身份（吴昊阳），数据保存在浏览器 localStorage 中。

## 使用说明（测试人员请看这里）

### 运行网页

1. 下载（或 clone）本仓库全部文件到本地，保持上述目录结构不变；
2. 使用 **谷歌 Chrome 浏览器** 直接双击打开 `index.html`（保证稳定性与一致性）；
3. 页面按手机小程序样式呈现，桌面端居中显示，窗口拉窄即为手机效果。

推荐体验路线（与原型流程一致）：

- **浏览 → 详情**：首页切换「全部 / 寻物 / 招领」分类，点击任意卡片进入详情页；
- **搜索**：点击首页顶部搜索框，输入关键词（如“校园卡”）或点击热门搜索词，可叠加类型 / 分类 / 地点筛选；
- **发布**：点击底部中间「＋」，切换寻物 / 招领，填写带 * 的必填项后提交，进入发布成功页；故意留空可看到逐项校验提示；
- **更新状态**：底部「我的」查看本人发布（演示账号“吴昊阳”预置了 2 条），点击「标记已找到」或在详情页标记；标记后详情页联系方式自动隐藏；
- **重置**：在「我的」页面底部点击「重置演示数据」可恢复初始状态。

### 运行单元测试

两种方式任选其一，测试用例完全相同（共 13 个，覆盖表单校验分支、搜索与组合筛选、排序、时间格式化、状态流转）：

- **浏览器方式**：用 Chrome 双击打开 `test/runner.html`，页面直接显示每个用例的通过情况；
- **Node 方式**：安装 Node.js（任意较新版本），在项目根目录执行以下任一指令：

  ```bash
  node --test test/core.test.js
  ```
  ```bash
  node --test test/**/*.test.js
  ```

## 技术说明

- 纯 HTML / CSS / 原生 JavaScript，无框架、无构建步骤；
- 单页应用：使用 `location.hash` 路由（`#/home`、`#/search`、`#/publish`、`#/success`、`#/detail/:id`、`#/mine`），兼容 `file://` 协议直接打开；
- 逻辑与界面分离：`js/core.js` 为纯函数逻辑层，被页面与单元测试共用；
- 数据持久化：`localStorage`（键 `laf_items_v1`），首次打开自动写入 9 条演示数据。
